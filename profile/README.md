## Mailward

Open Outlook PST, OST and OLM archives, plus MBOX, EML and MSG files, in the browser. The file is parsed on your own device and never uploaded. No Outlook needed, and it works on a Mac.

- Use it: [pst.aivismonitor.com](https://pst.aivismonitor.com/)
- Field notes on the formats: [email-archive-formats](https://mailward.github.io/email-archive-formats/), from implementing a parser for each
- Built by [Lei Wang](https://github.com/leivorn). Corrections and format edge cases are welcome as issues on the notes repository.
